# Issue tracker

Issues for this project live in GitHub Issues for `kevin-rieck/ostudio-web`. Use the `gh` CLI for issue operations.

## Conventions

- Create: `gh issue create --repo kevin-rieck/ostudio-web --title "..." --body-file <file>`
- Read: `gh issue view <number> --repo kevin-rieck/ostudio-web --comments`
- Edit: `gh issue edit <number> --repo kevin-rieck/ostudio-web ...`
- Comment: `gh issue comment <number> --repo kevin-rieck/ostudio-web --body "..."`
- Close: `gh issue close <number> --repo kevin-rieck/ostudio-web --comment "..."`

The desktop issue tracker remains in `kevin-rieck/project-cobalt`. Create cross-repository links explicitly when compatibility work affects both products.
